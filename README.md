# BTC-Signal Project

This repository contains scripts and data related to generating and analyzing Bitcoin trading signals.

## Project Structure

-   `scripts/`: Contains the core signal generation logic and other utility scripts.
-   `data/`: Stores historical market data, raw signals, and processed analysis results.
-   `logs/`: Directory for various application logs.
-   `venv/`: Python virtual environment with project dependencies.
-   `file_details.md`: Provides a detailed breakdown of the project's file and directory structure.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

-   Python 3.8+
-   Git

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/ivjiyeon/BTC-Signal.git
    cd BTC-Signal
    ```

2.  **Create and activate a virtual environment:**

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Install dependencies:**

    ```bash
    pip install -r requirements.txt # (Assuming a requirements.txt will be added later)
    ```

## Usage

To run the main Bitcoin signal generator:

```bash
python scripts/bitcoin_signal_generator.py
```
